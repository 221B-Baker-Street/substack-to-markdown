# Substack to NotebookLM Harvester

A lightweight Python utility designed to fetch articles from public Substack publication archives, strip UI boilerplate (subscribe buttons, headers, footers), and package them into clean Markdown files for NotebookLM audio podcast generation.

## Setup & Usage
1. Clone repository: `git clone https://github.com/221B-Baker-Street/substack-to-markdown.git`
2. Install requirements: `pip install -r requirements.txt`
3. Run the script: `python scraper.py`
